Who we are

The demo team behind this fixture site is a small group of engineers who care about measurable search performance. We write software that audits websites the way a senior SEO consultant would, except the software never gets tired and never skips a page. This about document deliberately reuses the homepage title so the duplicate title detector has an obvious target, and its meta description is far shorter than the recommended range so the length check fires as well. Notice that the page has no level one heading at all: the document opens with a level two heading, which trips the missing H1 rule and gives the repair engine a chance to promote that heading automatically.

How we work

Every engagement starts with a crawl. The crawler fetches robots.txt, inventories the XML sitemap, follows internal links up to a fixed depth, records the final status code of every URL, and notes every redirect hop so chains longer than one jump are flagged. The audit stage then evaluates the collected markup against a checklist that covers meta tags, headings, word counts, image alternative text, image dimensions for layout stability, social sharing tags, structured data, canonicalisation, mobile viewport, charset, language attributes, favicon presence, broken internal links, HTTPS usage, mixed content, host consistency, custom error pages, page weight and lazy loading. Nothing is guessed: every issue carries evidence copied straight out of the HTML so you can verify it in thirty seconds.

The repair stage reverses what it can. Titles are rebuilt from the heading one and the site name, descriptions are derived from the first meaningful paragraph and truncated at a natural sentence boundary, canonical links point at the page's own absolute URL, robots and viewport and charset and language attributes are injected when absent, social preview tags are generated, and missing structured data is added as tidy JSON. Anything that needs human judgement, such as rewriting thin copy or deciding whether a cross domain canonical is intentional, stays in the report as a manual recommendation with actionable advice instead of being silently changed.
