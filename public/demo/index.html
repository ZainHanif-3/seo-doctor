Welcome to the Demo Site

SEO Doctor fixture deliberately broken on purpose

This website is a controlled laboratory for SEO Doctor, a full crawl and repair tool built by the ZN DEVELOPER team. Every page here contains specific, intentional defects so the auditor has something real to find: missing titles, duplicate titles, absent descriptions, broken links, thin copy, images without alternative text, and no structured data at all. When you press the Optimize button, the tool rewrites this very HTML and hands you back a repaired copy of the entire site as a downloadable archive, complete with a file by file before and after diff so nothing happens in secret.

The crawl engine obeys robots.txt while it walks the site, yet it still reads and audits the robots.txt file itself so missing directives are reported rather than silently respected. It stays on the host you give it, stops at three levels of depth, never fetches more than thirty pages, and finishes inside a ten second budget with four polite parallel requests. That combination is fast enough for a five page fixture and safe enough to point at a production marketing site without melting the server or triggering rate limits.

Search engines reward clarity. A title tag between thirty and sixty characters tells the results page exactly what a document is about, a meta description between one hundred and forty and one hundred and sixty characters earns the click, one heading one defines the topic, and a canonical link stops duplicate URLs from splitting your ranking signals. This fixture deliberately omits most of those ingredients so you can watch the repair pipeline add them back with sensible, human readable values derived from the page content itself rather than keyword stuffed boilerplate.

Try it end to end: analyze this demo, review the scored issue table, select the problems you want repaired, press Optimize all, then download the repaired mirror. Everything runs server side in Node with no framework magic, no bundler, and no external services. Built by ZN DEVELOPER, CEO Zain Hanif.
